# Acerto

App PWA para controlar acertos de conta parcelados (ex.: venda de um celular em 13 parcelas descontadas aos poucos).

- Registra cada parcela descontada com data e valor; mostra quanto já foi pago e quanto falta.
- Gera a mensagem pronta para o WhatsApp, com um link de acompanhamento.
- Quem recebe o link vê o acerto atualizado (só leitura), e ele fica salvo no aparelho dela.
- Dados ficam no próprio celular (localStorage), sem servidor e sem login. Funciona offline.
- Backup e restauração em arquivo `.json` para trocar de celular.

Publicado no GitHub Pages: https://eldergithub.github.io/acerto/
No Android, abra no Chrome e toque em **Instalar app**.
